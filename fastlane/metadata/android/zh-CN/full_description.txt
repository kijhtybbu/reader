麦麦阅读器 — 一款离线优先的中文电子书阅读器
（Book's Story 的 GPL-3.0-only 分支）

无账号、无广告、无统计上报。支持 EPUB / PDF / TXT / FB2 / HTML / Markdown，书库、进度、
笔记式收藏与设置全部保存在本机。

【阅读与排版】
* Material You 主题与多套阅读配色预设，跟随系统深浅色
* 字号、行距、段距、字距、首行缩进、对齐、左右与上下边距逐项可调
* 排版按书覆盖：某本书单独调整字号或字体，不影响其它书；可一键恢复全局默认
* 支持导入字体文件，并检测中文字形覆盖情况（无中文字形时如实提示回退）
* 分页与滚动两种阅读模式，翻页动画、点击分区可选

【查词与词典】
* 内置 ECDICT（77 万词条），首次启动离线安装，无需联网
* 点按或长按单词弹出锚定在词上的词典卡片，可发音
* 可导入 MDX 词典或 StarDict 词典文件夹；MDX 可连同 .mdd 资源包一起导入
  （图片、样式表、字体、真人发音）
* 词条用 WebView 渲染，跟随阅读配色与系统字号缩放

【AI 翻译与语法】
* 双击段落，流式返回译文，并给出结构化语法分析（逐句展开）
* 兼容 OpenAI 接口，也可指向本地模型（Ollama / LM Studio / llama.cpp 等，无需 API Key）
* 结果按提示词版本、模型、目标语言、接口地址缓存在本地，再次打开同一段落秒回
* 设置页可查看缓存条数与体积，并一键清理

【收藏】
* 取词卡片与句尾都可一键收藏，全局收藏夹统一管理
* 单词显示词头、音标、释义与发音按钮；句子保存原文、译文与语法分析

【隐私】
* 无需注册登录，不采集使用数据
* 词典、书籍、缓存全部在本机；API Key 由 Tink 加密后保存
